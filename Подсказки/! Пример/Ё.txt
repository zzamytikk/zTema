  jQuery предоставляет мощную систему селекторов, основанную на CSS, позволяющую находить элементы DOM внутри функции $(). Эти запросы можно разделить на несколько ключевых категорий. 
Ниже приведен список всех основных видов запросов для поиска:
1. Базовые селекторы (Basic Selectors) 
Все элементы: $("*") — выбирает все элементы на странице.
По ID: $("#id") — выбирает уникальный элемент с заданным ID.
По классу: $(".class") — выбирает все элементы с указанным классом.
По имени тега: $("element") — выбирает все элементы, например, $("p") или $("div").
Комбинированный (множественный): $("h1, p, .className") — выбирает все элементы h1, p и элементы с указанным классом.
2. Селекторы иерархии (Hierarchy Selectors) 
Потомок (Descendant): $("ancestor descendant") — находит все элементы descendant, являющиеся потомками ancestor (например, $("div p")).
Дочерний (Child): $("parent > child") — находит элементы, являющиеся прямыми детьми (например, $("ul > li")).
Соседний (Next Sibling): $("prev + next") — находит элемент next, следующий сразу после prev.
Родственные (Siblings): $("prev ~ siblings") — находит все родственные элементы, следующие после prev.
3. Селекторы атрибутов (Attribute Selectors) 
Наличие атрибута: $("[attribute]") — элементы, у которых есть указанный атрибут (например, $("[href]")).
Точное совпадение: $("[attribute='value']") — атрибут равен значению.
Несовпадение: $("[attribute!='value']") — атрибут не равен значению.
Начинается с: $("[attribute^='value']") — значение атрибута начинается с указанной строки.
Заканчивается на: $("[attribute$='value']") — значение атрибута заканчивается на указанную строку.
Содержит: $("[attribute*='value']") — значение атрибута содержит указанную строку.
4. Селекторы фильтрации (Filters) 
Первый/Последний: $("p:first"), $("p:last").
Четные/Нечетные (начиная с 0): $("tr:even"), $("tr:odd").
Индекс (EQ): $("li:eq(2)") — выбирает 3-й элемент (индекс начинается с 0).
Больше/Меньше индекса: $("li:gt(2)") (индекс > 2), $("li:lt(2)") (индекс < 2).
Отрицание: $("input:not(.className)") — все input, не имеющие данного класса.
Заголовок: $(":header") — выбирает <h1> - <h6>.
5. Селекторы форм и состояний (Form/State Selectors) 
Типы ввода: $(":text"), $(":password"), $(":radio"), $(":checkbox"), $(":submit"), $(":file") и т.д.
Состояние: $(":checked") (выбранные радио/чекбоксы), $(":selected") (выбранные в списках), $(":disabled"), $(":enabled").
Поиск по значению: $(":input") — находит все input, textarea, select, button.
6. Вложенный поиск (find) 
Если нужно искать внутри уже выбранного элемента, используется метод .find():
javascript
$("#container").find(".item"); // Ищет .item внутри #container
7. Использование контекста 
Можно указать контекст поиска прямо в $():
javascript
$("div", "#myWrapper"); // Ищет div внутри элемента с id="myWrapper"
8. Специальные селекторы
Текущий элемент: $(this) — часто используется внутри событий.
Скрытые/Видимые: $(":hidden"), $(":visible").
