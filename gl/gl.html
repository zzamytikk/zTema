Презентация

День/Ночь или (Light/Dark mode) это функция сайта, которая позволяет пользователю менять оформление интерфейса между светлыми и темными тонами.
Пример




Подключение к сайту:


    <!-- Добавить в <head>..</head>: -->
    <script src="https://code.jquery.com/jquery-3.7.1.min.js" defer></script><!-- Библиотека jQuery -->
    <link href="https://zam.usite.pro/db/publ/zTema/1-0-0/m.css" rel="stylesheet"><!-- Вид -->
    <script src="https://zam.usite.pro/db/publ/zTema/1-0-0/m.js" defer></script><!-- Мозг -->
► Исходники(css, js): github (m. - Сокращённый вариант, ok. - Подробный)

    <!-- Добавить в <body>..</body>: -->
    <div class="zTemaX" ztema="0">
      <button class="B-Ig-DN0 zTemaO"><p></p><p></p></button>
      <button class="B-Ig-DN1"><p></p><p></p></button>
      <button class="B-Ig-DN2"><p></p><p></p></button>
    </div>
    
    <script>
    document.addEventListener('DOMContentLoaded', () => {
      zTema.on();//★ Запускаем 'Темaа сайта Авто/День/Ночь'
    });
    </script>
Полезная информация:
  • class="zTemaT" установит открытие меню сверху

    <div class="zTemaX zTemaT" ztema="0">
      <button class="B-Ig-DN0 zTemaO"><p></p><p></p></button>
      <button class="B-Ig-DN1"><p></p><p></p></button>
      <button class="B-Ig-DN2"><p></p><p></p></button>
    </div>
